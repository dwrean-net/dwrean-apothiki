# dwrean Αποθήκη

Το **dwrean Αποθήκη** είναι μια δωρεάν portable εφαρμογή για Windows που βοηθά στην απλή καταχώριση και διαχείριση υλικών αποθήκης, χωρίς εγκατάσταση και χωρίς εξωτερικό server.

## Δυνατότητες

- Καταχώριση ονομασίας υλικού
- Κωδικός αριθμός
- Θέση αποθήκευσης
- Είδος υλικού
- Επιλογή αποθήκης
- Προαιρετική φωτογραφία για κάθε υλικό
- Προεπισκόπηση φωτογραφίας και μεγέθυνση με κλικ
- Αναζήτηση σε όλες τις καταχωρίσεις
- Φίλτρα ανά είδος υλικού, αποθήκη και θέση
- Επεξεργασία και διαγραφή καταχωρίσεων
- Εκτύπωση αποτελεσμάτων με βάση τα ενεργά φίλτρα
- Εκτύπωση μόνο επιλεγμένων υλικών
- Εξαγωγή σε CSV
- Δημιουργία και επαναφορά Backup
- Τοπική βάση δεδομένων SQLite
- Ενσωματωμένη βοήθεια και πληροφορίες εφαρμογής
- Προσαρμοζόμενο περιβάλλον ώστε τα βασικά κουμπιά να παραμένουν ορατά και σε μικρότερο παράθυρο
- Υποστήριξη Ctrl+C, Ctrl+V, Ctrl+X και Ctrl+A στα πεδία κειμένου

## Λήψη

Η τελευταία έτοιμη έκδοση για Windows είναι διαθέσιμη από την ενότητα **Releases** του repository.

Δεν απαιτείται εγκατάσταση. Αποσυμπίεσε το αρχείο ZIP και εκτέλεσε το `dwrean Apothiki.exe`.

## Portable λειτουργία

Η εφαρμογή αποθηκεύει τα δεδομένα της τοπικά στον φάκελο `data` δίπλα στο εκτελέσιμο αρχείο. Οι φωτογραφίες των υλικών αποθηκεύονται στον φάκελο `data/images`.

Μπορείς επίσης να χρησιμοποιήσεις την ενσωματωμένη λειτουργία **Backup** για να δημιουργήσεις ένα ZIP που περιλαμβάνει τη βάση δεδομένων και όλες τις φωτογραφίες.
