# dwrean Αποθήκη

Portable εφαρμογή Windows για απλή διαχείριση αποθήκης.

## Δυνατότητες

- Καταχώριση ονομασίας υλικού
- Κωδικός αριθμός
- Θέση αποθήκευσης
- Είδος υλικού
- Επιλογή αποθήκης
- Προαιρετική φωτογραφία για κάθε υλικό
- Αναζήτηση σε όλες τις καταχωρίσεις
- Φίλτρα ανά είδος υλικού, αποθήκη και θέση
- Επεξεργασία και διαγραφή καταχωρίσεων
- Εκτύπωση όλων των αποτελεσμάτων ενός φίλτρου
- Εκτύπωση μόνο επιλεγμένων υλικών
- Εξαγωγή σε CSV
- Τοπική SQLite βάση δεδομένων χωρίς server

## Portable λειτουργία

Η εφαρμογή αποθηκεύει τα δεδομένα της στον φάκελο `data` δίπλα στο εκτελέσιμο αρχείο. Οι φωτογραφίες αντιγράφονται αυτόματα στον φάκελο `data/images`.

Για πλήρες αντίγραφο ασφαλείας ή μεταφορά σε άλλο υπολογιστή, κράτησε μαζί:

- `dwrean Apothiki.exe`
- ολόκληρο τον φάκελο `data`

## Build σε Windows

1. Εγκατάστησε Python 3.11 ή νεότερη.
2. Κατέβασε ή κάνε clone το repository.
3. Κάνε διπλό κλικ στο `build.bat`.
4. Το portable αρχείο θα δημιουργηθεί στον φάκελο `portable`.

Το πρόγραμμα δεν χρειάζεται εγκατάσταση στον υπολογιστή του τελικού χρήστη.
